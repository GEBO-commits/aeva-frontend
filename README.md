# 🎉 Event Planning App

A full-featured event planning web application that helps users plan their perfect event — from venues to vendors, DJs, photographers, catering, and more.

---

## ✨ Features

- 🤖 AI-Generated Event Plans — let AI build your full event plan automatically
- 📋 Plan By Yourself — step-by-step manual planning flow with skip options
- 🏛️ Venue & Vendor Selection — browse and select from cards with full details
- 📧 Fake Email Sending — simulate sending reservation emails to all vendors
- 👥 Guest Management — manage your guest list and send mass invites
- 💾 Persistent Sessions — stay logged in and keep your history after page refresh
- ✏️ Editable Plan Title — click to rename your plan inline
- 📱 Responsive Design — works across desktop and mobile

---

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm or yarn

### Installation

# Clone the repository
git clone https://github.com/Klara126/aeva-frontend.git

# Navigate into the project
cd aeva-frontend

# Install dependencies
npm install

# Start the development server
npm run dev

Then open http://localhost:5173 in your browser.
